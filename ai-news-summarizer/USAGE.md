# AI新闻总结小助手 - 使用指南

## 快速开始

### 第一步：安装扩展

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角的"开发者模式"开关
3. 点击"加载已解压的扩展程序"按钮
4. 选择 `ai-news-summarizer` 文件夹
5. 扩展安装成功！

### 第二步：配置API

首次使用需要配置API：

1. 访问任意新闻网站（如网易新闻）
2. 点击浏览器工具栏中的扩展图标（显示"AI"徽章）
3. 在弹出的popup中，点击"API配置"标签页
4. 填写API信息：
   - **API名称**：给你的API起个名字，比如"OpenAI"或"DeepSeek"
   - **API地址**：API的完整URL，例如：
     - OpenAI: `https://api.openai.com/v1/chat/completions`
     - DeepSeek: `https://api.deepseek.com/v1/chat/completions`
   - **模型名称**：要使用的模型，例如：
     - OpenAI: `gpt-3.5-turbo` 或 `gpt-4`
     - DeepSeek: `deepseek-chat`
   - **API密钥**：你的API密钥（以sk-开头）
5. 点击"添加API配置"按钮
6. 配置会自动保存到本地

### 第三步：使用扩展

1. 访问支持的新闻网站（网易新闻、新浪新闻、腾讯新闻、搜狐新闻）
2. 等待页面完全加载
3. 点击浏览器工具栏中的扩展图标
4. 在"新闻摘要"标签页中：
   - 点击"提取新闻内容"按钮
   - 等待内容提取完成
   - 点击"生成AI摘要"按钮
   - 等待AI生成摘要（通常几秒钟）
5. 查看生成的100字以内的摘要

## 详细说明

### 支持的新闻网站

目前支持以下新闻网站：

- **网易新闻** (163.com)
  - 包括网易新闻频道、订阅号等
  - 自动识别标题和正文内容

- **新浪新闻** (sina.com.cn)
  - 支持新浪新闻频道
  - 提取文章标题和正文

- **腾讯新闻** (qq.com)
  - 支持腾讯新闻页面
  - 自动提取主要内容

- **搜狐新闻** (sohu.com)
  - 支持搜狐新闻文章
  - 智能识别新闻内容

### API配置管理

#### 添加多个API

你可以配置多个API接口：

1. 在"API配置"标签页中填写第一个API信息
2. 点击"添加API配置"
3. 清空输入框，填写第二个API信息
4. 再次点击"添加API配置"
5. 重复以上步骤添加更多API

扩展会使用列表中的第一个API进行调用。如果第一个API失败，你可以手动删除它，让扩展使用下一个API。

#### 删除API配置

1. 在"API配置"标签页中找到要删除的API
2. 点击该API右侧的"删除"按钮
3. 确认删除

#### 清空所有配置

点击"清空所有配置"按钮可以删除所有已保存的API配置。

### 功能特性

#### 自动识别新闻页面

当你访问支持的新闻网站时，扩展图标会显示"AI"徽章，表示当前页面可以使用此扩展。

#### 智能内容提取

扩展会自动识别新闻页面的标题和正文内容，并过滤掉广告、导航栏等无关信息。

#### 100字摘要

AI会将新闻内容总结为100字以内的摘要，突出核心信息。

#### 本地存储

所有API配置都保存在本地浏览器中，不会上传到任何服务器，确保安全性。

## 常见问题

### Q: 为什么点击"提取新闻内容"没有反应？

A: 请检查以下几点：
1. 确保当前页面是支持的新闻网站
2. 确保页面已完全加载
3. 尝试刷新页面后重试
4. 检查浏览器控制台是否有错误信息

### Q: API调用失败怎么办？

A: 请检查：
1. API地址是否正确（包括协议https://）
2. API密钥是否有效且未过期
3. 模型名称是否正确
4. 网络连接是否正常
5. API服务是否可用（可以尝试用curl或Postman测试）

### Q: 生成的摘要不准确怎么办？

A: 可以尝试：
1. 使用更强大的模型（如gpt-4）
2. 检查新闻内容是否被正确提取
3. 尝试不同的API提供商

### Q: 可以在其他网站上使用吗？

A: 目前只支持特定的新闻网站。如果你想在其他网站上使用，可以：
1. 修改 `content.js` 文件，添加对应网站的内容提取逻辑
2. 或者修改 `manifest.json` 中的 `content_scripts.matches` 配置

### Q: API密钥安全吗？

A: API密钥保存在浏览器的本地存储中，不会上传到任何服务器。但请注意：
1. 不要在公共电脑上保存API密钥
2. 定期更换API密钥
3. 不要分享你的API密钥

### Q: 使用会产生费用吗？

A: 这取决于你使用的API提供商：
- OpenAI: 按使用量计费
- DeepSeek: 可能有免费额度
- 其他API: 请查看各自的定价政策

建议在使用前了解清楚API的定价策略。

## 高级使用

### 自定义内容提取

如果你想添加对其他网站的支持，可以编辑 `content.js` 文件：

```javascript
// 在 extractNewsContent() 函数中添加新的网站逻辑
else if (window.location.hostname.includes('your-site.com')) {
  title = document.querySelector('your-title-selector')?.textContent?.trim() || '';
  content = document.querySelector('your-content-selector')?.textContent?.trim() || '';
}
```

### 修改摘要长度

如果你想修改摘要的长度限制，可以编辑 `popup.js` 文件中的 `callApi()` 函数：

```javascript
// 修改这里的数字来调整摘要长度
if (summary.length > 100) {
  summary = summary.substring(0, 100) + '...';
}
```

### 自定义UI样式

如果你想修改扩展的外观，可以编辑 `popup.html` 文件中的 `<style>` 标签。
