# 网易新闻纯净阅读模式 - Chrome扩展

## 功能说明

这个Chrome扩展程序为网易新闻详情页面提供纯净阅读体验，能够：

- ✅ 保留标题和正文内容
- ❌ 隐藏广告和侧边栏
- ❌ 移除推荐内容和评论区
- ❌ 隐藏导航栏和其他干扰元素
- 🎨 优化阅读体验，提供舒适的排版

## 安装方法

1. 打开Chrome浏览器
2. 在地址栏输入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `news-reader-mode` 文件夹
6. 扩展安装完成！

## 使用方法

### 手动模式
1. 访问任意网易新闻详情页面（如：https://news.163.com/xxx/article/xxx）
2. 点击浏览器工具栏中的扩展图标
3. 点击"开启纯净阅读模式"按钮
4. 页面将自动切换到纯净阅读模式

### 自动模式
1. 点击扩展图标打开弹出窗口
2. 点击"自动开启纯净模式"按钮
3. 之后访问任何网易新闻详情页面都会自动应用纯净阅读模式

## 技术实现

### 文件结构
```
news-reader-mode/
├── manifest.json      # 扩展配置文件
├── content.js         # 内容脚本
├── styles.css         # 样式文件
├── popup.html         # 弹出界面
├── popup.js           # 弹出界面逻辑
└── icons/             # 图标文件
    ├── icon16.svg
    ├── icon48.svg
    └── icon128.svg
```

### 核心功能

#### 1. 内容识别
- 标题选择器：`.post_title`
- 正文内容：`.post_body`
- 文章信息：`.post_info`

#### 2. 隐藏元素
通过CSS选择器隐藏以下元素：
- 导航栏：`.ntes_nav_wrap`
- 面包屑：`.post_crumb`
- 侧边栏：`.post_side`
- 推荐内容：`.post_recommends`
- 评论区：`.post_comment`
- 广告模块：`.ad_module`
- 其他干扰元素

#### 3. 样式优化
- 最大宽度限制：800px
- 字体大小：18px
- 行高：1.8
- 优化的间距和排版

## 兼容性

- 支持的域名：`*.163.com`
- 支持的页面类型：新闻详情页（包含 `/article/` 或 `/dy/article/` 路径）
- Chrome版本：需要支持Manifest V3（Chrome 88+）

## 开发说明

### 修改匹配规则
编辑 `manifest.json` 中的 `content_scripts.matches` 字段：

```json
"matches": [
  "*://*.163.com/*",
  "*://163.com/*"
]
```

### 添加新的隐藏元素
在 `styles.css` 中添加新的CSS规则：

```css
.news-clean-mode .your-selector {
  display: none !important;
}
```

### 调整阅读样式
修改 `styles.css` 中的样式规则来自定义阅读体验。

## 注意事项

1. 扩展仅在网易新闻详情页生效
2. 首次安装后需要刷新页面才能生效
3. 自动模式设置会保存在浏览器中
4. 如遇到兼容性问题，请检查页面结构是否发生变化
