# 网易新闻纯净阅读模式 Chrome 扩展 - 安装指南

## 安装步骤

### 方法一：直接加载扩展（推荐）

1. **下载扩展文件**
   - 下载整个`netease-reading-mode`文件夹到本地

2. **打开Chrome扩展管理页面**
   - 在Chrome浏览器地址栏输入：`chrome://extensions/`
   - 或者通过菜单：Chrome菜单 → 更多工具 → 扩展程序

3. **开启开发者模式**
   - 在扩展管理页面右上角，打开"开发者模式"开关

4. **加载扩展**
   - 点击"加载已解压的扩展程序"按钮
   - 选择下载的`netease-reading-mode`文件夹
   - 点击"选择文件夹"

5. **验证安装**
   - 扩展应该出现在扩展列表中
   - 浏览器工具栏应该显示扩展图标（可能需要点击拼图图标查看所有扩展）

### 方法二：打包为.crx文件（高级用户）

1. **打包扩展**
   - 在扩展管理页面，点击"打包扩展程序"
   - 选择`netease-reading-mode`文件夹作为扩展根目录
   - 点击"打包扩展程序"按钮
   - 生成.crx文件和.pem密钥文件

2. **安装.crx文件**
   - 将.crx文件拖拽到Chrome扩展管理页面
   - 或者在扩展管理页面点击"加载已解压的扩展程序"，选择.crx文件

## 使用方法

### 手动切换阅读模式

1. 访问网易新闻详情页面
2. 点击浏览器工具栏中的扩展图标
3. 在弹出界面中点击"切换阅读模式"按钮
4. 页面将切换到纯净阅读模式，只显示标题和正文内容

### 自动启用阅读模式

1. 点击浏览器工具栏中的扩展图标
2. 在弹出界面中开启"自动启用阅读模式"选项
3. 之后访问网易新闻详情页面时，将自动启用阅读模式

### 页面内切换

在阅读模式下，页面右上角会显示一个"退出阅读"按钮，点击即可退出阅读模式。

## 测试扩展

1. 打开扩展文件夹中的`test_page.html`文件
2. 在Chrome中加载扩展后访问该测试页面
3. 测试扩展的各项功能是否正常工作

## 常见问题

### 1. 扩展无法加载

- 确保选择了正确的文件夹（`netease-reading-mode`）
- 检查manifest.json文件是否有语法错误
- 确保所有必需文件都存在

### 2. 扩展图标不显示

- 点击浏览器工具栏右侧的拼图图标
- 找到"网易新闻纯净阅读模式"扩展
- 点击图钉图标固定到工具栏

### 3. 阅读模式不生效

- 确保访问的是网易新闻详情页面
- 尝试刷新页面
- 检查扩展是否有最新版本

### 4. 页面元素显示异常

- 网易新闻页面结构可能已更改
- 请等待扩展更新或联系开发者

## 卸载扩展

1. 打开Chrome扩展管理页面（chrome://extensions/）
2. 找到"网易新闻纯净阅读模式"扩展
3. 点击"移除"按钮
4. 确认移除
