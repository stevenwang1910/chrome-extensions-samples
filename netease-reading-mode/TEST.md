# 网易新闻纯净阅读模式扩展测试指南

## 测试目的

验证网易新闻纯净阅读模式扩展是否能够正确隐藏非必要元素，优化阅读体验，并解决以下问题：
1. "Unchecked runtime.lastError: Could not establish connection"错误
2. 正文被悬浮跟帖图标遮挡的问题
3. 扩展在某些页面不起作用的问题

## 测试环境

- Chrome浏览器（最新版本）
- 扩展版本：v1.1
- 测试页面：
  1. `test_fixed.html` - 模拟网易新闻页面的测试页面
  2. `https://www.163.com/dy/article/KKJFBPJA0514R9M0.html` - 实际网易新闻页面
  3. `https://www.163.com/news/article/KKK2A9AJ000189FH.html` - 另一种网易新闻页面格式

## 测试步骤

### 1. 安装扩展

1. 打开Chrome浏览器
2. 进入扩展管理页面（chrome://extensions/）
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择`netease-reading-mode`文件夹
6. 确认扩展已成功加载

### 2. 测试基本功能

#### 2.1 测试页面加载

1. 打开`test_fixed.html`测试页面
2. 检查页面右上角是否出现"纯净阅读"按钮
3. 检查浏览器控制台是否有错误信息

#### 2.2 测试阅读模式切换

1. 点击"纯净阅读"按钮
2. 验证以下元素是否被隐藏：
   - 顶部导航栏
   - 侧边栏
   - 广告内容
   - 推荐阅读
   - 评论区
   - 分享按钮
   - 页脚
   - 悬浮跟帖图标
   - 悬浮广告

3. 验证以下元素是否保留并优化：
   - 文章标题（居中显示，字体加大）
   - 正文内容（优化排版，增加行距）
   - 图片（居中显示，自适应大小）

4. 检查按钮文本是否变为"退出阅读"
5. 再次点击按钮，验证页面是否恢复正常

### 3. 测试实际网易新闻页面

#### 3.1 测试第一种页面格式

1. 访问`https://www.163.com/dy/article/KKJFBPJA0514R9M0.html`
2. 重复2.1和2.2的测试步骤
3. 特别注意悬浮跟帖图标是否被正确隐藏

#### 3.2 测试第二种页面格式

1. 访问`https://www.163.com/news/article/KKK2A9AJ000189FH.html`
2. 重复2.1和2.2的测试步骤
3. 验证扩展是否在此页面格式下正常工作

### 4. 测试弹出界面功能

1. 点击扩展图标打开弹出界面
2. 测试"启用阅读模式"按钮
3. 测试"自动启用阅读模式"开关
4. 测试"重置设置"按钮

### 5. 错误处理测试

1. 检查浏览器控制台是否还有"Unchecked runtime.lastError"错误
2. 测试在非网易新闻页面上扩展是否正确禁用
3. 测试页面快速刷新时扩展是否稳定

## 预期结果

1. 扩展在所有测试页面上正常加载和工作
2. 阅读模式能够正确隐藏所有非必要元素
3. 正文内容不被任何悬浮元素遮挡
4. 没有JavaScript错误
5. 弹出界面功能正常
6. 页面切换和刷新时扩展稳定

## 常见问题及解决方案

### 问题1：扩展按钮未出现

**可能原因**：
- 扩展未正确加载
- 页面URL不匹配
- JavaScript错误

**解决方案**：
- 检查扩展管理页面确认扩展已启用
- 检查manifest.json中的matches规则
- 查看浏览器控制台错误信息

### 问题2：部分元素未被隐藏

**可能原因**：
- 元素选择器不匹配
- 页面结构变化
- CSS优先级问题

**解决方案**：
- 更新content.js中的选择器列表
- 检查页面实际DOM结构
- 增强CSS选择器优先级

### 问题3：内容显示异常

**可能原因**：
- 内容选择器不准确
- 样式冲突
- 页面布局特殊

**解决方案**：
- 更新内容识别算法
- 调整CSS样式
- 添加特定页面的处理逻辑
